# Data in this folder

| File | What it is | Source and licence |
|---|---|---|
| `banana_features.csv` | Six colour numbers + label for each labelled banana photo (the photos themselves are not stored here) | Extracted with `build_dataset.py` from the *Ripe Unripe Banana Dataset*, Mendeley Data, https://data.mendeley.com/datasets/y3649cmgg6/1, licensed **CC BY 4.0** |
| `rainfall_india_1901_2015.csv` | Monthly and annual rainfall (mm) for 36 IMD subdivisions, 1901–2015 | India Meteorological Department, published on data.gov.in (Open Government Data Licence – India) |
| `../samples/*.jpg` | Two example photos (one ripe, one unripe) for the app's "Try an example" option and the notebook | *Ripe Unripe Banana Dataset*, Mendeley Data, **CC BY 4.0** (unchanged copies) |
| `imd_regions.csv` | Friendly names, broad zones and **approximate** centre points of the 36 subdivisions, for the map | FasalScope (MIT) |
